Nastavení připojení k OneDrive

Pro ukládání fotografií je potřeba propojit aplikaci s vaším firemním Microsoft 365 účtem.

  1. 1Přihlaste se na portal.azure.com → Azure Active Directory → Registrace aplikací → Nová registrace
  2. 2Název: cokoliv (např. FotodokumentaceApp), typ: Účty v libovolné org. adresáři
  3. 3URI přesměrování: Jednostránková aplikace (SPA) → vložte URL adresu tohoto souboru (nebo http://localhost)
  4. 4Po vytvoření zkopírujte ID aplikace (klienta) a vložte níže
  5. 5V sekci API oprávnění přidejte: Microsoft Graph → Files.ReadWrite

Nastavení se uloží pouze v tomto prohlížeči.
